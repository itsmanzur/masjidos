How to use

Put prayer times on a page

Install & set location

Activate MasjidOS → Welcome: timezone, coordinates, calculation method.

Edit with Elementor

Drag a Shortcode widget onto the page.

Paste shortcode

Copy ready-made examples from MasjidOS → Features or Docs.

Publish

Or use MasjidOS Gutenberg blocks if the page is block editor.
