# Self-hosted MasjidOS fonts

Shared by Admin UI, public widgets, and TV Display (`tv-fonts.css`).

- **Plus Jakarta Sans** — SIL Open Font License 1.1 (Primary Latin UI & Tabular Numbers)
- **Hind Siliguri** — SIL Open Font License 1.1 (Primary Bangla UI & Content, weights 400/500/600/700)
- **Amiri** — SIL Open Font License 1.1 (Classical Naskh Arabic for Quran, Hadith, Duas & Sacred Script, weights 400/700)
- **Readex Pro** — SIL Open Font License 1.1 (Modern Arabic UI & Headings)
- **Outfit, Cairo, Noto Sans Bengali** — SIL Open Font License 1.1 (Display & Legacy Fallback)

No requests are made to `fonts.googleapis.com` or `fonts.gstatic.com` at runtime.
